





:class:`BoundaryConditions`
===========================


.. py:class:: ansys.health.heart.settings.settings.BoundaryConditions(/, **data: Any)

   Bases: :py:obj:`BaseSettings`


   
   Stores settings/parameters for boundary conditions.

   Manages boundary condition parameters for cardiac simulation including
   pericardium constraints, valve mechanics, and pressure loading.

   :Parameters:

       **robin** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           Parameters for pericardium spring/damper boundary conditions.

       **valve** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           Parameters for valve spring boundary conditions.

       **end_diastolic_cavity_pressure** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           End-diastolic pressure configuration.













   .. rubric:: Examples

   >>> bc = BoundaryConditions(
   ...     robin={"stiffness": 1.0, "damping": 0.1}, valve={"spring_constant": 100.0}
   ... )
   >>> print(bc.robin["stiffness"])
   1.0
