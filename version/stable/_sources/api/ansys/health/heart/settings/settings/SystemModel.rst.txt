





:class:`SystemModel`
====================


.. py:class:: ansys.health.heart.settings.settings.SystemModel(/, **data: Any)

   Bases: :py:obj:`BaseSettings`


   
   Stores settings/parameters for the system model.

   Manages system-level model configuration including circulatory system
   models and ventricular-specific parameters.

   :Parameters:

       **name** : :class:`python:str`, default: "ConstantPreloadWindkesselAfterload"
           Name of the system model implementation.

       **left_ventricle** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           Parameters specific to left ventricle modeling.

       **right_ventricle** : :class:`python:dict`\[:class:`python:str`, :obj:`Any`] | :data:`python:None`, default: :data:`python:None`
           Parameters specific to right ventricle modeling.













   .. rubric:: Examples

   >>> system = SystemModel(
   ...     name="ConstantPreloadWindkesselAfterload",
   ...     left_ventricle={"volume": 150.0},
   ...     right_ventricle={"volume": 120.0},
   ... )
   >>> print(system.name)
   ConstantPreloadWindkesselAfterload
